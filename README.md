# SecureDesk

Outil Windows de déploiement d'un accès bureau à distance sécurisé :
**WireGuard** (tunnel point à point) + **TSplus Remote Access** (multi-session) + **multiOTP Credential Provider** (TOTP hors ligne).

> Développement en cours. Le plan de conception est dans [`docs/PLAN.md`](docs/PLAN.md).
